BACKEND ERROR CODES:

  Authentication & Authorization:
    UNAUTHORIZED (401) - No valid auth token

    INVALID_USER_ID (400) - Bad user ID
    
  Data Validation:
    INVALID_DATA (400) - Bad request format
    MISSING_RESUME (400) - Resume required
    EMPTY_RESUME (400) - Resume is empty
    VALIDATION_ERROR (400) - Field validation failed
    
  Resource Errors:
    NOT_FOUND (404) - Resource doesn't exist
    NO_RESUME (404) - User has no resume
    
  Server Errors:
    AI_FAILED (500) - AI service error
    PDF_GENERATION_FAILED (500) - PDF failed
    ANALYSIS_FAILED (500) - Analysis failed
    
  Rate Limiting:
    RATE_LIMITED (429) - Too many requests
